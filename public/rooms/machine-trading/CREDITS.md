## Machine

Vault, doors, wheel, circuit core and system racks are original procedural Three.js geometry created for this interface. This is an imagined Chicago-inspired digital space, not a measured or documented CBOT basement/vault reconstruction.
The visible work items and team roles are labeled example workflows, with changes confined to the current visit.

## Markets

All charts are deterministic synthetic index illustrations, explicitly labeled with the reference edition date November 18, 2026. They are not historical prices, current quotes, COT positions, signals or performance claims.
Market pane preferences and notes are saved only when the user clicks Save workspace, into this browser's local storage. No notes are sent to a server.
