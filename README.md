# Mind + Machine

The Mahlmania website opens in the Mind garden. Atlas opens at `/atlas/` from the main navigation.

Use Node.js 24 and `npm ci`. Run `npm run dev` to work on the homepage. Run `npm run build:site` to build the whole site in `dist/`.

Vercel builds the repository root. The Atlas build uses a pinned upstream revision and includes its attribution and data notices. Publication of the two third-party datasets for commercial use requires separate rights review. See [the Atlas build notes](atlas/README.md).
